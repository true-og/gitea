# Gitea template overrides

Files here mirror Gitea's `templates/` tree and are installed to `/opt/gitea/custom/templates/`
by `install-custom-templates.sh`. Gitea loads a custom template *instead of* the built-in one, so an
override silently pins that template to the Gitea version it was copied from.

## After upgrading Gitea
Diff each override against the new release's copy of the same file and re-apply only the label
change if the upstream template changed:

    tar xzf gitea-<ver>.tar.gz gitea-<ver>/templates/user/auth/external_auth_methods.tmpl
    diff gitea-<ver>/templates/user/auth/external_auth_methods.tmpl ~/gitea-upgrade/custom-templates/user/auth/external_auth_methods.tmpl

Use `upgrade-gitea.sh check <version>` before every upgrade. It compares upstream copies of every
full override between the active and target binaries and blocks on any difference. If a page renders
broken or blank after an upgrade, remove the affected file from `/opt/gitea/custom/templates/` and
restart Gitea to fall back to the built-in template, then update the canonical source here.
